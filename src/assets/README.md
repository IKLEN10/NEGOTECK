# assets/

Carpeta reservada para recursos estáticos propios del proyecto (logotipos en SVG,
íconos personalizados, imágenes locales). Actualmente las imágenes de muestra se
cargan desde Unsplash/Pravatar como mock data; al integrar contenido real, colócalo
aquí y referencia las rutas desde los componentes o desde `src/data/`.
